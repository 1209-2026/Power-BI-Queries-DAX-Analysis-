# Power BI Queries & DAX Analysis

## Project Overview

This mini-project focuses on analyzing the Sample Superstore 2019 dataset using Microsoft Power BI.

The project demonstrates data cleaning and transformation, data modeling, DAX calculations, and interactive report development to support automated business reporting and KPI analysis.

## Business Scenario

Management wants automated reporting and KPI calculations to monitor sales and profitability and gain insights into overall business and product performance.

## Dataset

**Dataset:** Sample - Superstore 2019.xls

The dataset contains sales and business-related information used to analyze sales performance, profitability, products, customers, and shipping.

## Tools

* Microsoft Power BI
* Power Query
* DAX

## Data Preparation

The dataset was imported into Power BI and cleaned and transformed using Power Query Editor.

The data preparation process included transforming the dataset into a suitable structure for analysis and preparing the required fields for reporting and calculations.

## Data Modeling

A proper data model was created to support analysis and reporting.

A date hierarchy was also created to enable time-based analysis and filtering.

## DAX Measures

The project includes multiple DAX measures for KPI calculations and business analysis, including:

* Total Sales
* Total Profit
* Profit Margin %
* Running Total
* Year-over-Year (YoY) Growth

## Calculated Columns

Two calculated columns were created to support business analysis:

* Profitability Category
* Shipping Delay

## Report Pages

### Executive Analysis

The Executive Analysis page provides an overview of the main business KPIs and overall performance.

### Product Analysis

The Product Analysis page focuses on product-level performance and provides insights into sales and profitability.

## Interactive Features

The report includes interactive features to allow users to explore the data dynamically, including:

* Slicers
* Drill-through functionality
* Dynamic filtering
* Interactive visuals

## Technical Requirements

* 5+ DAX measures
* 2 calculated columns
* 2 report pages
* 3+ interactive visuals
